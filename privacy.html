Privacy Policy — GBND

Last updated: 18 November 2026

GBND is an internal tool operated by verisyn.co that runs the "Boring News" live stream on YouTube. It is used only by its operator, for the operator's own YouTube channel.

What data we access

With the read-only YouTube permission (youtube.readonly), GBND reads:

  • the status and health of our own channel's live streams (for example "active" or "inactive", "good" or "bad");
  • public live chat messages on our own live streams, if the chat vote feature is turned on.

GBND cannot upload, edit or delete anything on YouTube, and it does not read any other channel's private data.

How we use it

We use this data only to check that our live stream is reaching YouTube and to show stream health to the operator. If chat votes are on, we count chat messages to show live results on the stream.

Storage and sharing

  • The access token is stored only on our own server, in a file readable only by the service account.
  • The stream status is kept as a small local file that is overwritten every minute.
  • We do not sell, share or transfer Google user data to anyone. We do not use it for advertising or to train AI models.

GBND's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

GBND uses YouTube API Services. By using it you also agree to the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

Revoking access

You can remove GBND's access at any time at myaccount.google.com/permissions. When access is removed, we delete the stored token.
